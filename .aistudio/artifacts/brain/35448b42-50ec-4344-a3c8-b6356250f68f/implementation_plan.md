# 打線模式排版優化與球員打席紀錄自動化系統

本計畫針對「打線模式 (Lineup Mode)」進行全面的空間與視覺排版重構，解決壘包圖示溢出、計時器佔用獨立橫列、字級未能自適應等問題；並全新打造「球員打席紀錄自動追蹤系統」，在每次打席結算時自動寫入球員今日歷次打席結果，且無縫整合呈現在打線模式的球員欄位中，保持介面簡潔俐落且不增添雜亂彈窗。

---

### 使用者確認與關鍵決策 (User Review & Confirmed Decisions)

> [!IMPORTANT]
> 依據前期提問與使用者明確確認之決策，本架構依循以下核心原則實作：

- **打席紀錄呈現位置**：不採用彈窗或額外跳出方框，直接利用打線模式（Lineup Mode）球員列釋出之橫向空間，以俐落、低視覺干擾的文字標籤序列呈現（例如：`安`、`K`、`四`、`全` 或 `1B`、`K`、`BB`）。
- **計時器整合位置**：徹底移除原本獨立佔據一整橫列（`h-10 lg:h-12`）的計時器列，直接整合至中央「局數與好壞球資訊方塊」內，將寶貴的垂直高度釋放給壘包、BSO 燈號與九局計分表。

## 1. 核心概念與功能亮點 (Overview & Core Concept)

```
┌────────────────────────────────────────────────────────────────────────┐
│                        打線模式 (Lineup Mode) 2.0                      │
├────────────────────┬───────────────────────────────┬───────────────────┤
│ 客隊打線 (24%)     │ 中央精華轉播板面 (52%)        │ 主隊打線 (24%)    │
│                    │                               │                   │
│ 隊名 (無冗長副標)  │ [比分] [局數+計時器] [比分]   │ 隊名 (無冗長副標) │
│                    │ ───────────────────────────── │                   │
│ 1. 游 陳傑憲 #24   │       [現正打者 vs 投手]      │ 1. 右 林立 #39    │
│    CF · 安 K 四    │ ───────────────────────────── │    2B · 二安 飛   │
│                    │    [壘包菱形] │ [BSO 圓燈]    │                   │
│ 2. 二 岳東華 #98   │  (左右收納空間充裕、不破邊)   │ 2. 中 陳晨威 #98  │
│    2B · 雙殺       │ ───────────────────────────── │    CF · 三安 保   │
│                    │     [九局比分表 R / H / E]    │                   │
│ (少人數自動放大)   │                               │ (少人數自動放大)  │
└────────────────────┴───────────────────────────────┴───────────────────┘
```

1. **壘包完全內縮不破界**：
   - 左右兩側打線欄寬度微調為 `24%`，中央精華區擴展至 `52%`。
   - 菱形壘包（Diamond）與 BSO 圓燈容器重設為彈性等比縮放，確保在任何解析度與雙螢幕投影下皆有充裕邊距（Safe Margins），徹底解決壘包圖示溢出界線問題。
2. **零虛擲空間——計時器無縫整合**：
   - 刪除獨立計時器橫列，將其嵌入頂部中央「局數切換方塊」內（上方顯示局數箭頭與局數，下方並排或整合倒數秒數與動態警示色）。
   - 整體畫面釋放出超過 48px 的垂直空間，使球員打席名單和下方的九局計分表擁有更舒適的呼吸感。
3. **消除視覺噪音——移除副標題**：
   - 移除球隊 Header 中的「AWAY TEAM」與「HOME TEAM」英文冗餘標籤，隊名採強烈對比與純淨隊徽呈現。
4. **打擊率欄位更換為守備位置 (Position)**：
   - 原先顯示打擊率（如 `.300`）的位置改為顯示正式守位標籤（如 `CF`、`SS`、`1B`、`P`、`DH` 等），更貼合現場先發守備佈局需求。
5. **少人數自適應大字級 (Dynamic Scale-to-Fit)**：
   - 根據先發打線人數動態切換排版規模：
     - **9 人標準編制**：自動放大字體（`text-base lg:text-lg`）、加大背號字級與點擊高度（`py-2`），充分運用垂直空間，不留大片尷尬空白。
     - **10–12 人（含 DH / 增額）**：中等字級（`text-sm lg:text-base`，`py-1.5`）。
     - **13 人以上**：緊湊模式（`text-xs lg:text-sm`，`py-1`）。
6. **球員今日各打席結果自動累積與顯示**：
   - 當操作者在控制台按下 `1B`、`2B`、`3B`、`HR`、`BB`、`OUT`（或三振、三上三下）時，系統自動將打席代碼紀錄至當前打者的歷程陣列 `atBats`。
   - 在打線模式各球員列的姓名/守位右側，以簡短精緻的文字標籤依序排列今日打席（例：`安`、`K`、`四`、`全` 或 `1B`、`K`、`BB`），即時反映球員今日手感。

## 2. 使用者體驗與視覺設計 (UX & Visual Design)

- **無藥丸邊框哲學 (Zero-Pill Discipline)**：
  - 打席結果不使用厚重彩色圓角藥丸，而是採用細緻的微底色或高對比文字徽章，例如安打以翡翠綠（`text-emerald-400`）、全壘打以金黃（`text-amber-400 font-black`）、三振以暗紅（`text-rose-400`）、保送以冰藍（`text-sky-400`）呈現，一目了然且維持專業轉播質感。
- **打線目前打者高亮指示**：
  - 當前輪到打擊的球員列以發光外框（`ring-1 ring-blue-500`）與球隊主色微漸層背景呈現，並附上 `AT BAT` 呼吸燈。
- **計時器狀態回饋**：
  - 整合於局數方塊中的計時器，倒數至 8 秒內時維持醒目的紅色脈衝警示（`animate-pulse text-rose-400`），平時則為低調內斂的明黃色。

### 資料模型擴充
- 在 `Player` 型別中新增 `atBats?: string[]`，記錄每位球員當日歷次打席結果。
- `ActionType` 支援在快速結算、出局、四壞等事件觸發時，自動派發包含該打席代碼的狀態變更。
- 支援 `CLEAR_AT_BATS` 或在重置賽事時一併清空。

### 觸發流程與自動寫入對應表
| 操作動作 | 自動記錄代碼 (atBats) | 是否計入團隊安打 (Hits) |
|---|---|---|
| 1B (一壘安打) | `1B` (安) | 是 (+1) |
| 2B (二壘安打) | `2B` (二安) | 是 (+1) |
| 3B (三壘安打) | `3B` (三安) | 是 (+1) |
| HR (全壘打) | `HR` (全) | 是 (+1) |
| BB (四壞保送) | `BB` (保) | 否 |
| K (三振出局) | `K` (三振) | 否 |
| OUT (一般出局) | `OUT` (出局) | 否 |
| 3OUT (三上三下) | 當前打者記錄 `OUT` | 否 |

## 4. 驗證與測試計畫 (Verification & Test Cases)

1. **版面比例與壘包不破界驗證**：
   - 開啟打線模式，確認壘包菱形與 BSO 圓燈完全被安全包覆於中央區塊，即便在小視窗或手機預覽縮放時均無橫向溢出或裁切。
2. **計時器整合測試**：
   - 驗證中央局數方塊下方或內部正確顯示倒數計時數字，啟動/暫停、時間到蜂鳴均正常運作，原獨立橫列已不復見。
3. **守位取代打擊率驗證**：
   - 確認打線列中原打擊率欄位已變更為球員守備代號（如 `SS`, `CF`, `DH` 等）。
4. **少人數動態大字級測試**：
   - 切換至 9 人以下名單，確認字體、打序與背號顯著放大且行距舒適；切換至 12 人以上名單時自動回復精簡模式不產生溢出。
5. **打席自動紀錄與即時顯示測試**：
   - 依序點擊 `1B`、`BB`、`HR`、`OUT`，驗證打線模式中對應球員列立即浮現該打席的結果標籤，換局後仍持續累積且歷程清晰。
   - 點擊「復原 (Undo)」時確認上一動打席紀錄正確同步撤銷。
